Uso dos prompts em `05-prompts`

Este diretório contém os templates e referências usados para construir os prompts enviados à LLM.

Arquivos principais:
- `system_prompt.md` — instruções rígidas e schema de saída (ENVIADO À LLM).
- `persona.md` — descrição da persona do avaliador (ENVIADO À LLM quando presente).
- `user_template.md` — template onde serão injetados enunciado, gabarito, código do aluno e o campo opcional `{{CONCEITOS_A_AVALIAR}}` (ENVIADO À LLM).
- `concepts.md` — lista de conceitos de POO e instruções de uso. (ENVIADO À LLM quando presente).
