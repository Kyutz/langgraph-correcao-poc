Implemente a evolução da classe Java 'Figura' seguindo os requisitos divididos por etapas:

Exercício 1.5 - Composição e Novos Atributos:

1. Adicione um segundo atributo privado para um sol, chamado 'sol2', da classe 'Circulo'.

2. Garanta que ambos os sóis sejam instanciados e posicionados corretamente quando a figura for desenhada.

Exercício 1.7 - Modularização (Métodos):

1. Crie um método público chamado 'porDoSol()'.

2. Este método deve conter a lógica para mover os dois sóis verticalmente para baixo (usando o método 'moverVerticalLento' dos objetos Circulo).

Exercício 1.8 - Interação entre Objetos:

1. Adicione um atributo privado da classe 'Pessoa' chamado 'morador'.

2. Altere a lógica da classe para que a pessoa apareça na cena.

3. Implemente ou altere um método para que o 'morador' caminhe em direção à casa somente APÓS o pôr do sol ter ocorrido.
